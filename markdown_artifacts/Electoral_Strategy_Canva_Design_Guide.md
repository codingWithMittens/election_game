## GETTING STARTED

### 1. Create Canva Account
- Go to www.canva.com
- Sign up (free tier works fine)
- Optional: Upgrade to Canva Pro ($13/month) for:
  - AI image generation
  - Background remover
  - Brand kit (save your colors/fonts)
  - More templates

### 2. Set Up Custom Card Size

**Click "Create a design" → "Custom size"**
- **Width**: 2.75 inches
- **Height**: 3.75 inches
- **Units**: Inches
- Click "Create new design"

**Why these dimensions?**
- Standard poker card: 2.5" × 3.5"
- We add 0.125" bleed on all sides (2.75" × 3.75")
- This ensures professional printing with no white edges

## STEP-BY-STEP: CREATING YOUR FIRST CARD

Let's create "Infrastructure Investment" as an example.

### Step 1: Create the Card Template

**A. Set Up Guides**
1. Click **"Guides"** in top menu (or press `G`)
2. Add margin guides:
   - Left: 0.125"
   - Right: 0.125"
   - Top: 0.125"
   - Bottom: 0.125"
3. This creates your "safe zone" - keep text inside these guides

**B. Add Background**
1. Click **"Elements"** in left sidebar
2. Search "rectangle"
3. Drag a rectangle to cover entire canvas
4. Set color to `#F8F9FA` (off-white)

---

### Step 2: Create Header Section

**A. Add Header Background**
1. **Elements** → Search "rectangle"
2. Drag rectangle to top of card
3. **Size**: Full width × 1.2" height
4. **Color**: Click color → "+" → Enter `#2C5F99` (blue for Policy cards)
5. Add gradient (Canva Pro feature):
   - Click color → Gradient
   - Start: `#2C5F99`
   - End: `#1E3A5F`
   - Direction: Top to bottom

**B. Add Card Name**
1. Click **"Text"** → "Add a heading"
2. Type: "INFRASTRUCTURE INVESTMENT"
3. **Font**: Click font dropdown → Search "Oswald" → Select "Oswald Bold"
4. **Size**: 28px
5. **Color**: White
6. **Alignment**: Center
7. **Transform**: Click "…" → "Uppercase" (or just type in caps)
8. Position at top of header

**C. Add Type Label**
1. **Text** → "Add a subheading"
2. Type: "Policy · Economy"
3. **Font**: Roboto Medium
4. **Size**: 14px
5. **Color**: White
6. **Opacity**: 70% (click color → adjust opacity slider)
7. **Letter spacing**: 1.5px (Text → Spacing → Letter spacing)
8. Position below card name

---

### Step 3: Add Icon/Image Area

**Option A: Use Canva Elements**
1. **Elements** → Search "bridge icon" or "construction"
2. Drag icon to center of card
3. **Size**: ~180px
4. **Color**: Change to match your theme
5. Add background rectangle behind it (light blue)

**Option B: Generate with AI (Canva Pro)**
1. **Apps** → Search "Magic Media" or "DALL-E"
2. Prompt: "Simple flat icon of a bridge under construction, minimal design, blue and gray colors"
3. **Style**: Vector, Flat Design
4. Generate → Drag to card
5. Resize to 180px

**Option C: Upload Your Own**
1. Create icon in Figma or download from Flaticon.com
2. **Uploads** → "Upload files"
3. Drag to card

---

### Step 4: Add Cost Badge

1. **Elements** → Search "circle"
2. Drag circle to top-right corner (overlapping image area slightly)
3. **Size**: 60px × 60px
4. **Color**: `#D4342C` (red)
5. **Border**: Click "Border" → Width 3px → Color White
6. **Add text**:
   - **Text** → "Add a heading"
   - Type: "3"
   - **Font**: Inter Bold
   - **Size**: 28px
   - **Color**: White
   - Center on circle (use alignment tools)
7. **Group**: Select circle + text → Right-click → "Group"

---

### Step 5: Create Effect Section

**A. Add Background Box**
1. **Elements** → Rectangle
2. **Size**: Full width (minus margins) × ~250px height
3. **Color**: White
4. **Effects** → "Shadow" → Soft shadow
5. **Corner radius**: Click "Corner rounding" → 8px
6. Position in middle section of card

**B. Add Effect Labels & Text**

**PRIMARY EFFECT:**
1. **Text** → "Add a subheading"
2. Type: "PRIMARY EFFECT:"
3. **Font**: Roboto Bold
4. **Size**: 12px
5. **Color**: `#2C5F99` (blue)
6. **Transform**: Uppercase
7. **Letter spacing**: 1px

**Effect Description:**
1. **Text** → "Add a body text"
2. Type: "+3 lean in Rust Belt states"
3. **Font**: Inter Regular
4. **Size**: 18px
5. **Color**: `#212529` (almost black)
6. **Highlight "+3" in green** (`#059669`):
   - Select just "+3"
   - Change color to green

**Secondary Text:**
1. Add another text box
2. Type: "(PA, MI, WI, OH)"
3. **Font**: Inter Regular
4. **Size**: 16px
5. **Color**: `#6C757D` (gray)

**BACKLASH:**
1. Repeat same process
2. Label: "BACKLASH:" (red color `#DC2626`)
3. Text: "-1 lean in Low-tax states (TX, FL, WY)"
4. Highlight "-1" in red

**SPECIAL:**
1. Label: "SPECIAL:" (purple `#8E44AD`)
2. Text: "If 'Union Support' played this turn, +1 additional"

---

### Step 6: Add Flavor Text Section

1. **Elements** → Rectangle
2. **Size**: Full width × ~80px height
3. **Color**: Gradient from `#F8F9FA` to `#FFFFFF`
4. **Border**: Top border only, 1px, `#E9ECEF`
5. **Add text**:
   - Type: *"Rebuilding America, one bridge at a time."*
   - **Font**: Georgia Italic (or Merriweather Italic)
   - **Size**: 14px
   - **Color**: `#495057` (gray)
   - **Alignment**: Center
   - Add quotes around text

---

### Step 7: Save as Template

1. **File** → "Make a copy"
2. Rename: "Card Template - Policy"
3. This is now your master template!

## CREATING CARDS WITH DICE MECHANICS

For cards like "Viral Social Media Campaign 🎲":

### Add Dice Roll Table

1. **Elements** → Rectangle
2. **Color**: `#FFF9E6` (light yellow)
3. **Border**: 2px dashed, `#F39C12` (orange)
4. **Corner radius**: 6px
5. **Add dice icon**:
   - **Elements** → Search "dice"
   - Or use emoji: 🎲
6. **Add table**:

**Create table manually:**
```
Title: "ROLL 1d6" (Roboto Bold, 14px, uppercase)

Row 1: "1-2 │ Flop: +1 lean only"
Row 2: "3-5 │ Viral: +2 lean"
Row 3: "6   │ Mega: +3 + draw card"
```

**Or use Canva table:**
1. **Elements** → Search "table"
2. Select 2-column, 3-row table
3. Fill in text
4. Adjust styling

## CARD BACKS

Create a matching card back:

### Design Steps

1. Create new Canva document (same size: 2.75" × 3.75")
2. **Background gradient**:
   - Top: `#1E3A5F` (blue)
   - Bottom: `#8B1A1A` (red)
   - Or solid color: `#2C3E50` (dark blue-gray)

3. **Add centered content**:
   ```
   ┌─────────────────┐
   │                 │
   │   ELECTORAL     │
   │   STRATEGY      │
   │                 │
   │   [US Map Icon] │
   │                 │
   │  Campaign for   │
   │  the Presidency │
   │                 │
   └─────────────────┘
   ```

4. **Border**:
   - Gold/yellow frame: `#F39C12`
   - 8px width
   - 12px corner radius

5. **Add subtle pattern** (Canva Pro):
   - **Elements** → "Patterns" → Search "stars" or "political"
   - Overlay with low opacity (10-20%)

## EXPORTING FOR PRINTING

### Print-and-Play (Home Printing)

**Export Settings:**
1. **Click "Share"** → "Download"
2. **File type**: PDF Standard
3. **Pages**: All (if multi-page document)
4. **Flatten PDF**: No (keep layers for editing later)
5. **Crop marks and bleed**: Yes (if available in Pro)
6. **Click Download**

**Printing at Home:**
1. Open PDF
2. Print on heavy cardstock (110lb or heavier)
3. Cut along bleed lines
4. Optional: Sleeve cards with penny sleeves + playing cards for rigidity

---

### Professional Printing

**For TheGameCrafter or PrintNinja:**

**Export Settings:**
1. **File type**: PNG
2. **Quality**: High (300 DPI minimum)
3. **Background**: Transparent if uploading to template

**Alternative:**
1. **File type**: PDF Print
2. **Color profile**: CMYK (if option available)
3. **Bleed**: Include

**Upload to Printing Service:**
- TheGameCrafter: Upload each card individually
- PrintNinja: Upload as print sheet (arrange 9 cards per sheet first)

## CREATING PRINT SHEETS (9 Cards Per Sheet)

To print efficiently at home:

### Step-by-Step

1. **Create new Canva document**:
   - **Custom size**: 8.5" × 11" (letter)
   - **Or**: A4 (8.27" × 11.69")

2. **Add grid**:
   - 3 columns × 3 rows
   - Use **Elements** → "Grids" → "3×3 grid"
   - Or manually place cards

3. **Place cards**:
   - Upload your finished card designs
   - Drag into each grid cell
   - Ensure proper spacing (~0.25" between cards for cutting)

4. **Add crop marks** (optional):
   - **Elements** → "Lines"
   - Small lines at corners of each card

5. **Export**:
   - PDF Standard
   - Print at 100% scale (no "fit to page")

**Cards per sheet**: 9
**Total sheets needed for 85 cards**: 10 sheets (+ 5 extra cards on 10th sheet)

## TROUBLESHOOTING

### "My text is getting cut off when printed"
- Ensure text is inside margin guides (0.125" from edge)
- Check your printer settings - print at 100% scale

### "Colors look different when printed"
- Screens show RGB, printers use CMYK
- Blues and reds may appear darker when printed
- Test print one card first to check colors

### "Cards look pixelated"
- Ensure you're using 300 DPI for export
- Use vector icons when possible (scale without quality loss)
- Avoid stretching small images

### "Canva won't let me use that font"
- Some fonts require Canva Pro
- Alternative free fonts:
  - Oswald → Anton, Bebas Neue
  - Inter → Roboto, Open Sans
  - Georgia → Libre Baskerville
